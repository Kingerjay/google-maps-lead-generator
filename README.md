# Google Maps Lead Generator

A local dashboard for running Google Maps lead-generation projects (niche + location), built around the open-source [GoSOM Google Maps Scraper](https://github.com/gosom/google-maps-scraper) (MIT licensed).

## Status

Work in progress. GoSOM runs locally and is driven through its REST API.

## Planned architecture

React + Vite + Tailwind dashboard -> small Node.js server -> GoSOM REST API -> CSV -> Google Sheets
